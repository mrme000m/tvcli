TV Cron Orchestrator v1.0.0
============================================

Commands:
  schedule   Generate a Hermes cron command or register a scheduled scan
  watchlist  Batch-run indicators across a symbol list immediately
  monitor    Compare open positions against live indicator signals
  hooks      Install shell/gateway hook templates

Global Options:
  --json              Output JSON
  --agent             Agent mode (simplified JSON)
  --verbose, -v       Verbose output
  --dry-run           Print commands without executing
  --help, -h          Show this help

Schedule Options:
  --name <name>               Job name
  --schedule <expr>           Cron expression or natural language
  --symbols <list>            Comma-separated symbols
  --indicators <list>         Comma-separated indicator names
  --tf <tf>                   Timeframe (1m,5m,15m,1h,4h,1D)
  --preset <name>             Indicator preset
  --out-dir <dir>             Output directory for JSON files
  --alert-threshold <level>   Minimum signal to alert (A+, STRONG, etc.)
  --sentinel-dir <dir>        Write sentinel files on alerts

Watchlist Options:
  --symbols <list>            Comma-separated symbols (required)
  --indicators <list>         Comma-separated indicators (required)
  --tf <tf>                   Timeframe (default: 15m)
  --preset <name>             Preset (default: auto)
  --bars <n>                  Bars (default: 500)
  --out <file>                Write aggregated output to file
  --parallel                  Run symbols in parallel

Monitor Options:
  --position-file <file>      JSON file with open positions
  --indicators <list>         Confirmation indicators
  --tf <tf>                   Timeframe for check
  --alert-on-mismatch         Alert when signal opposes position
  --out <file>                Write report to file

Examples:
  tv-cron-orchestrator.cjs schedule --name "BTC Hourly" --schedule "0 * * * *" \
    --symbols BTCUSDT --indicators precision-sniper,ict-auto-validated-smc --tf 1h

  tv-cron-orchestrator.cjs watchlist --symbols BTCUSDT,ETHUSDT \
    --indicators precision-sniper --preset scalping --tf 15m --json

  tv-cron-orchestrator.cjs monitor --position-file ./positions.json \
    --indicators self-aware-trend-system,quantum-ribbon --alert-on-mismatch
